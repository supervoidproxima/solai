# Refusals

What `/solai` never does, whatever it is asked. Each one exists because the alternative is
silent damage rather than a visible failure.


- Write a vault artefact directly. The engine writes, after a gate.
- Rewrite a `body-sha` to silence a stamp mismatch. That converts a detected defect into an
  undetectable one, and it is the worst single action available here.
- Overwrite a hand-edited region. The user wins inside a region too.
- Edit an append-only file, or edit doctrine. A vault waives a principle with a reason; it
  never rewrites one.
- Delete. Retirement moves the artefact and names its fate: leave, migrate, regenerate, orphan.
- Describe a vault as healthy, complete, ready, governed, covered or done while the
  anti-avoidance assertion is red and the vault is over fourteen days old.
- Create more than one new artefact class in a turn, or diagnose the need for machinery and
  build it in the same turn.

## What `check --fix` may touch

A closed set, and it is closed because the alternative is a vault that looks clean and is not:

- renaming a key per the vocabulary's normalisation map
- adding a missing `[]` to a declared list field
- regenerating a stamp on a file whose body the engine itself produced

It never fixes a status, a link target, an enum value or a body heading. Each of those is a
judgement, and a tool that guesses at judgement is worse than one that reports and stops.

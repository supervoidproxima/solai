# EVALS - place

Binary assertions over a run of this skill. The last two outrank the rest.

| ID | Assertion | Failing step |
|---|---|---|
| E1 | Counts were printed before any question was asked | Step 2 |
| E2 | Only the questions the archetype declares were asked | Step 2 |
| E3 | Output language and first artefact were both asked | Step 2 |
| E4 | A plan table was shown before any apply | Steps 2, 5 |
| E5 | An engine refusal was relayed as written, and not worked around | Steps 2, 5 |
| E6 | The hat was named on every turn that wrote | Step 0 |
| E7 | `adopt` ran read-only, and the not-checked section was relayed | Step 3 |
| E8 | No coverage figure was reported without its denominator | Step 1 |
| E9 | No hand-edited region or file was overwritten | Steps 2, 5 |
| E10 | No class was created without naming real items for its first cards | Step 5 |
| E11 | The words healthy, complete, ready, governed, covered and done were absent while the anti-avoidance assertion was red | all |
| E12 | This run did not create more machinery than the vault produced content since the last run | all |

E11 and E12 are structural: failing either fails the run whatever the rest of the score.

## Thresholds

- 12 of 12: nothing to change.
- 11 of 12: propose a targeted edit to the failing step.
- Below 11, or any failure of E11 or E12: propose a structural revision, and say plainly what
  was built that should not have been.
